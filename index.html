Como interpretar os números

Simulação mensal de API

Custo estimado (US$) = chamadas por mês × [(tokens de entrada × preço de entrada por milhão) + (tokens de saída × preço de saída por milhão)] ÷ 1.000.000. É um cenário ilustrativo, não cotação ou fatura. Cache, processamento multimodal, ferramentas, lotes, faixas de contexto e tokens internos de raciocínio podem mudar o total. Tokens de raciocínio faturados como saída precisam estar incluídos na estimativa de saída.

O que o índice de inteligência mede?

É uma pontuação agregada de testes padronizados do Artificial Analysis (v4.3.2 nesta base). Ela representa desempenho geral do benchmark, não probabilidade de acerto, ROI ou qualidade garantida para a tarefa da sua empresa. A versão v5, publicada em 27/10/2026, usa metodologia diferente.

Diferença entre custo de API e custo por tarefa

O custo por tarefa do benchmark é a média ponderada que o Artificial Analysis mediu para executar seus próprios testes. Não é preço unitário por token e não deve ser multiplicado pelas tarefas reais da sua empresa como previsão de fatura. O modo “Seu gasto mensal” usa os preços de entrada/saída informados nesta base e o volume preenchido por você.

O que é a fronteira eficiente?

São os modelos para os quais nenhum outro na mesma amostra oferece ao mesmo tempo índice igual ou maior com custo igual ou menor (com pelo menos uma vantagem estrita). A fronteira é recalculada conforme a métrica de custo escolhida.

Fontes, data e limitações

Dados de modelo (24 configurações, preços de API e custo por tarefa): ResearchCollab, leitura de 15/10/2026, a partir do Artificial Analysis. Nova metodologia v5 (27/10/2026). Os preços dependem de provedor, região, modalidade e regras comerciais e podem ter mudado. O app não atualiza automaticamente e não envia os dados preenchidos a servidores.
